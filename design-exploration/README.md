# Aster design preview

This is a buildless, browser-only front-end prototype of the design direction in [`../docs/DESIGN_BRIEF.md`](../docs/DESIGN_BRIEF.md). Serve `dist/` with a local static HTTP server and open its root URL.

## Included screens

- Home and first-use empty states
- Applications
- Profile with experience, documents, and provider settings
- Email draft and review
- Public-source job alerts
- Contextual browser-extension review flow
- Notifications, settings, and four-step onboarding

The prototype uses one light “Sage & ink” visual system and a custom “Guiding A” logo concept. It is a design preview, not the final approved brand or the React/FastAPI application.

## Preview limitations

No authentication, backend, persistence, AI provider, file upload, monitoring scheduler, job fetch, Gmail handoff, or real application tracking is connected. Sample content is labeled. Preview controls display explanatory messages instead of claiming that private data was saved or an external action happened. The prototype loads no remote fonts or assets.
