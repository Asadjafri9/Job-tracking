# Rolevo design system

Design exploration artifact for DGN-002; not wired into `apps/web` or `apps/extension`. The existing [browser preview](../design-exploration/README.md) informed the starting Sage & ink palette. These tokens refine it with explicit semantic color pairs and stronger control/focus boundaries.

## Artifacts

- [`tokens/tokens.css`](tokens/tokens.css): semantic light-theme pairs, type scale, spacing, shape, focus, and reduced-motion tokens.
- [`logos/`](logos/): owner-selected Rolevo R symbol with horizontal, symbol-only, monochrome, and reversed SVG variants; [`logos/preview.html`](logos/preview.html) shows toolbar-size variants.
- [`components/COMPONENTS.md`](components/COMPONENTS.md): reusable component/state and accessibility contract.
- [`rendered/contrast-specimen.png`](rendered/contrast-specimen.png): rRolevo-rendered semantic text, status, control-border, and focus-ring contrast specimen.
- [`rendered/rolevo-16.png`](rendered/rolevo-16.png), [`rolevo-24.png`](rendered/rolevo-24.png), and [`rolevo-32.png`](rendered/rolevo-32.png): rendered mark-size review assets. [`rendered/rolevo-monochrome.png`](rendered/rolevo-monochrome.png) is the full monochrome lockup. The mark is a compact R-shaped path; small-size visual validation is recorded in DGN-002 evidence.
- [`components/components.css`](components/components.css) and [`components/index.html`](components/index.html): static specimen for review; no application behavior or product integration.

The owner selected Rolevo as the product name and the R mark for product design. The Sage & ink palette and typeface remain design-system choices. This is not a claim of trademark clearance or domain availability; see [`docs/evidence/DGN-006.md`](../docs/evidence/DGN-006.md). Contrast calculations and rendered specimens are recorded in [`docs/evidence/DGN-002.md`](../docs/evidence/DGN-002.md).
