## Implementation

- Added a shared error envelope with stable codes, request UUIDs, safe validation field errors, sanitized HTTP/unexpected errors, and `Cache-Control: no-store` on API responses.
- Added explicit contract version negotiation (`X-Copilot-Contract-Version`) and strict numeric `MAJOR.MINOR.PATCH` client-version checking (`X-Copilot-Client-Version`). Both headers are optional; unsupported contract majors, malformed client versions, and client versions below the published minimum return a sanitized 426 envelope. `GET /api/v1/meta` reports API/contract versions and minimum client version.
- FastAPI exposes its authoritative schema at `/api/v1/openapi.json`; `docs/openapi.json` and `apps/web/src/api/generated.ts` are generated deterministically. The web API wrapper uses the generated OpenAPI paths for typed requests and responses.
- Unknown API paths remain JSON 404 errors and do not fall through to dashboard HTML. This foundation does not mount an SPA fallback.
